# Color Palette Specification - PujaCircle

| Color Role | Name / Concept | Hex / HSL Value | Usage Guidelines |
| :--- | :--- | :--- | :--- |
| **Primary** | Sacred Saffron | `#F97316` / `hsl(28, 92%, 52%)` | Primary CTAs, active highlights, key iconography. |
| **Secondary** | Deep Maroon | `#781326` / `hsl(348, 65%, 26%)` | Headers, brand accents, secondary badges. |
| **Background** | Warm Ivory Neutral | `#FAF8F5` / `hsl(40, 33%, 98%)` | Base page canvas providing warmth over stark white. |
| **Card Surface** | Pure Clean White | `#FFFFFF` / `hsl(0, 0%, 100%)` | Container cards, popovers, modal surfaces. |
| **Foreground / Text** | Deep Charcoal | `#1C202A` / `hsl(220, 20%, 14%)` | High-contrast readable body text. |
| **Accent / Highlight**| Temple Gold | `#F5B82E` / `hsl(42, 85%, 55%)` | Verification badges, ratings stars, subtle highlights. |
| **Muted Surface** | Sandalwood Gray | `#EFECE6` / `hsl(35, 20%, 92%)` | Disabled states, subtle card borders, chips. |
| **Destructive** | Terracotta Red | `#DC2626` / `hsl(0, 72%, 51%)` | Booking cancellation, address removal, error alerts. |
| **Success** | Holy Tulsi Green | `#15803D` / `hsl(142, 71%, 38%)` | Phone verified badges, booking confirmed status. |

---

## Contrast & Accessibility (WCAG 2.1 AA)

- Primary Saffron (`#F97316`) on Dark Charcoal (`#1C202A`) exceeds **7.8:1**.
- Foreground text on Warm Ivory background exceeds **13.2:1**.
- Secondary Maroon on Ivory exceeds **9.4:1**.
