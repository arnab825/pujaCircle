# Branching Strategy - PujaCircle

## Branch Naming Guidelines

- **Features**: `feature/<feature-name>` (e.g. `feature/address-modal`)
- **Fixes**: `fix/<bug-name>` (e.g. `fix/slot-date-timezone`)
- **Documentation**: `docs/<topic>` (e.g. `docs/booking-flow`)
- **Hotfixes**: `hotfix/<patch>` (e.g. `hotfix/otp-rate-limit`)

Main Branches:
- `main`: Production-ready release branch.
- `develop`: Primary integration branch for active sprint features.
